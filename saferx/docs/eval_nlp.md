## 结论

1. **实体识别是真正的瓶颈**：词典法 precision 0.934 但 recall 仅 0.506（商品名、缩写、实验化合物 DRUG_N 不在 DDInter 词典内），端到端 F1 被实体召回拖住。
2. 关系四分类上，TF-IDF + 逻辑回归（0.862）显著优于关键词规则（0.602）。但要注意本评测**只取 gold 实体对**、不含负例检测，属偏乐观的设置；DrugBank 句式高度模板化（"may increase the risk of..."），char n-gram 足以捕获。
3. 因此 0.862 并不代表「小模型胜过 BioBERT」——文献中 BERT 类模型在该语料上报告 0.75~0.86，差异主要来自评测设置（是否含实体识别、是否含负例）。真实差距体现在**端到端**：词典实体 F1 仅 0.656，端到端会明显低于 0.86；换用 BioBERT 实体（0.877）后瓶颈才转移到关系侧。
4. 重复检查：测试集与训练集完全相同的掩码句子占 6.1%，剔除后 micro-F1 为 0.864（与全量基本一致），说明结果不是靠句子重复刷出来的。
5. **BioBERT 已完成实体识别微调、未做关系四分类**：实体侧 CPU 微调 3 epoch 得到 P 0.872 / R 0.882 / F1 0.877（见 eval_ner_biobert.md），瓶颈从「找不到药名」转为「DRUG_N 类不均衡」（该类 F1 仅 0.385）；关系侧未做 BERT 微调，原因是 gold 药对上的 TF-IDF 已达 0.862、接近文献区间上限，边际收益低于成本，属有意识的取舍而非未完成。
